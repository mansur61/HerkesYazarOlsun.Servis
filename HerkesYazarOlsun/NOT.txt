
--------- PostgreSQL Server için ------------- 
dotnet ef migrations add AddCarouselDuyuruRenk --project HerkesYazarOlsun.DataLayer

ekleneni dbye yansýtmak için

dotnet ef database update --project HerkesYazarOlsun.DataLayer

Son eklenen migration'ý kaldýrmak için

dotnet ef migrations remove

Mevcut migration'larý görmek için:
dotnet ef migrations list



---------  SQL Server için -------------
Bu komut, DataLayer/SqlServerMigrations içinde SQL Server için migrationlarý oluþturacaktýr.
dotnet ef migrations add InitialMigration --context SqlServerContext --output-dir SqlServerMigrations --project HerkesYazarOlsun.DataLayer

Migration'ý veritabanýna uygulamak için:
dotnet ef database update --context SqlServerContext --project HerkesYazarOlsun.DataLayer  

 Publish ederken Windows için doðru RID ile yap:
 dotnet publish -c Release -r win-x64 --self-contained false
